## 3. 실험에서 확인한 사실

동일한 1,000명 데이터를 대상으로 실행한 결과, SIMD 방식의 암호화 시간과 검색·통계 계산 시간이 사용자별 방식보다 짧게 측정되었습니다.

암호화 시간은 약 938.9배, 검색·통계 계산 시간은 약 229배 차이가 나타났습니다.

## 4. 실험의 한계 및 후속 작업

- 암호화 시간과 복호화 시간은 각각 1회 측정한 값임
- 검색·통계 시간은 3회 측정한 중앙값임
- 반복 실험을 통해 측정값의 변동을 추가 확인할 필요가 있음
- 사용자 2,000명, 4,000명 실험은 아직 수행하지 않음
- SIMD와 사용자별 방식의 메모리 사용량은 아직 측정하지 않음

## 5. 데이터 규모별 성능 비교
