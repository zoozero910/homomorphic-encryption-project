# 동형암호 기반 개인정보 검색 및 통계 처리

## 1. 프로젝트 개요

Microsoft SEAL의 BFV 동형암호를 사용하여 가상 사용자 데이터에 대한 다중 조건 검색 및 조건부 통계를 수행하는 프로그램입니다.

지역과 연령대 조건을 암호문 상태에서 결합하여 조건을 만족하는 인원 수와 구매 금액 합계를 계산합니다. 평균 구매 금액은 최종 합계와 인원 수를 복호화한 후 계산합니다.

## 2. 개발 환경

- 언어: C++17, Python
- 라이브러리: Microsoft SEAL 4.7.2
- 개발 환경: Apple Silicon Mac, VS Code, CMake
- 암호화 방식: BFV
- `poly_modulus_degree`: 8192
- 평문 모듈러스: 20비트 batching 소수

## 3. 구현 기능

- 가상 사용자 CSV 데이터 생성 및 읽기
- 지역·연령대 다중 조건 검색
- 조건부 인원 및 구매 금액 합계 계산
- 복호화 후 평균 구매 금액 계산
- SIMD 슬롯을 이용한 배치 처리
- Rotation을 활용한 슬롯 합산
- 사용자별 암호화와 SIMD 방식의 실행 시간 비교
- 노이즈 예산 측정
- 평문 계산을 이용한 정확성 검증

## 4. 주요 파일 설명

| 파일 | 역할 |
|---|---|
| `generate_users.py` | 가상 사용자 데이터 생성 |
| `users.csv` | 가상 사용자 데이터 |
| `read_users.cpp` | CSV 파일 읽기 확인 |
| `region_statistics.cpp` | BFV를 이용한 지역별 통계 및 검색 기초 구현 |
| `multi_condition.cpp` | 지역·연령대 다중 조건 검색 |
| `simd_conditional_stats.cpp` | SIMD 기반 조건부 구매 금액 합산 |
| `extended_stats.cpp` | 지역 10종·연령대 6종 및 평균 계산 |
| `benchmark.cpp` | 사용자별 방식과 SIMD 방식의 초기 성능 비교 |
| `benchmark_large.cpp` | 대규모 데이터 실험용 메모리 절약형 성능 비교 |
| `results/` | 실험 결과 TXT, Markdown, 가상 데이터 CSV 보관 |

## 5. 최종 실험 구성

- 사용자 수: 1,000명 / 2,000명 / 4,000명
- 지역: 10종
- 연령대: 6종
- 구매 금액: 1,000원 단위
- 검색 조건: 서울 + 20대
- 비교 방식: 사용자별 암호화 / SIMD 배치 암호화

## 6. 실험 결과

| 사용자 수 | 사용자별 계산 시간(ms) | SIMD 계산 시간(ms) |
|---|---:|---:|
| 1,000명 | 5,680.453 | 25.965 |
| 2,000명 | 11,331.501 | 26.138 |
| 4,000명 | 22,715.571 | 27.602 |

세 데이터 규모에서 두 방식 모두 평문 계산과 동일한 결과를 출력했습니다.

측정값은 `benchmark_large.cpp`의 단일 실행 결과이며, 반복 실험에 대한 통계적 분석은 수행하지 않았습니다.

## 7. 실행 방법

프로젝트 폴더에서 다음 명령어를 실행합니다.

```bash
python3 generate_users.py
cmake -S . -B build
cmake --build build --target benchmark_large
./build/benchmark_large
```

`generate_users.py`의 `user_count` 값을 변경하면 가상 사용자 수를 조절할 수 있습니다.

기존 `users.csv`는 덮어써지므로 필요한 데이터는 실행 전에 별도로 보관합니다.

## 8. 연구 범위와 한계

- 실제 개인정보가 아닌 가상 사용자 데이터를 사용했습니다.
- 암호화·연산·복호화를 하나의 로컬 프로그램에서 수행했습니다.
- 검색 조건 자체를 암호화하는 기능은 구현하지 않았습니다.
- SIMD 방식은 현재 설정에서 한 행의 최대 4,096명까지 처리하도록 구현했습니다.
- 평균은 암호문 합계와 인원 수를 복호화한 후 계산했습니다.
- 실험 결과는 현재 구현 및 측정 환경을 기준으로 해석해야 합니다.
